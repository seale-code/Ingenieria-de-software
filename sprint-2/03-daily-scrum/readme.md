# 3. Daily Scrum — Seguimiento del Sprint 02

La Daily Scrum sirve para inspeccionar el avance hacia el Sprint Goal y adaptar el plan. **No se declaran reuniones históricas** si no hay registros verificados en el repositorio.

## Preguntas de seguimiento (formato sugerido)

1. ¿Qué progreso concreto se logró hacia el objetivo del Sprint 2?
2. ¿Qué se trabajará a continuación?
3. ¿Qué obstáculo puede impedir la entrega o la revisión?

## Reglas del registro

- Registrar fecha, participantes y links a commits/PR/Issues; no usar solo "avanzado".
- Si no hubo reunión, dejar **"sin registro"** en lugar de atribuir asistencia o tareas ejecutadas.
- Mantener los impedimentos visibles en GitHub Projects.
