# Diseño de pantallas

1. Inicio de sesión: correo, contraseña y acceso según rol (pendiente).
2. Panel: KPIs de ventas, pedidos y stock bajo.
3. Ventas: buscador, catálogo, selección, cantidades, total y confirmar.
4. Pedidos: crear, consultar por código, preparar, entregar o cancelar.
5. Inventario: existencias, reservas, entradas y alertas.
6. Reportes: resumen por período.

**Guía visual sugerida:** interfaz limpia, consistente y accesible; evitar copiar logos o recursos protegidos de empresas reales. Usar datos y marca académica propia cuando sea posible.
